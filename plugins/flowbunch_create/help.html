Create flowBunch

Scans a folder of FCS files and creates a flowBunch object (package cytoElements) with its phenotype table (pheno) and panel table (panel). The report shows both tables, the cell count per file and the acquisition timeline.

  • FCS folder: folder holding the .fcs files (not searched recursively). From step… lists the folders of the previous steps that hold FCS files, for instance the split FCS files of a Split concatenated FCS step. The next Browse starts in the parent of the last folder you picked, so that a neighbouring folder is easy to choose.
  • flowBunch name: proposed from the folder name until you type one.
  • Cytometer: flow, spectral, mass or none.
  • Language for date: language passed to fb_update_pheno_dates for the dates of the files (English, French, German, Italian, Spanish, Portuguese or Dutch).
  • Cofactor: optional. Empty means the default of the cytometer.
  • Test mode: builds the object and the report without writing the flowBunch file.

Output

The step folder (<id>_<label>) holds data/ with the flowBunch file, to continue the analysis in later steps, flowbunch_create_report.html, console.log, run_parameters.json and session_info.txt.
