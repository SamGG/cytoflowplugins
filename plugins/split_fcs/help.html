Split concatenated FCS

Parses a concatenated FCS file (cells from several files merged together and clustered), extracts features and exports cells as FCS files.

  • Concatenated FCS file: the clustered file. Channels are read from its header. The folder of the file you pick is remembered and proposed next time.
  • File channel: integer channel identifying the original FCS file. Proposed: first channel matching sample_no, then sample, then file_no.
  • File mapping (XLSX/CSV, optional): gives the original FCS file name of each file number. Two layouts are recognised. If the file is named like the file channel (e.g. file_no.csv or file_no.xlsx), its first column is the integer number and its second column the name. Otherwise the file must be an XLSX: its pheno tab (or its only tab) must contain a column named like the file channel, and the File name column is chosen among the other columns of that tab (file_name is proposed first, then sample_id). Without a mapping, files are identified by their number.
  • Cluster channel: integer channel holding the cluster. Proposed: first channel matching cluster, then phenograph, then flowsom.
  • Cluster mapping (XLSX/CSV, optional): same two layouts. A file named like the cluster channel (e.g. cluster_no.csv) holds the number and the name in its first two columns. Otherwise an XLSX whose clusters tab (or only tab) has the columns clustering_id, cluster_no and cluster_name; the selected cluster channel must be listed in clustering_id, which is checked below the field. Without a mapping, clusters are identified by their number.
  • Output tables: XLSX and/or TSV.
  • Split FCS mode: None writes no FCS; File one FCS per file; Cluster one per cluster; Cluster x File one folder per cluster holding one FCS per file; File x Cluster one folder per file holding one FCS per cluster.
  • Heatmap markers (MFI): markers shown in the cluster heatmap.
  • Report markers (MFI): markers whose MFI is reported per cluster and file.

Marker lists. Markers are the channel marker names ($PnS) of the FCS file; channels without a marker name and the file and cluster channels are not listed. Click a marker to select or unselect it. Copy puts the selected markers on the clipboard, separated by tabs. Paste replaces the selection with the markers found in the clipboard (separated by tabs, new lines, commas or semicolons; names are matched without regard to case, and channel names are accepted too). Markers that are not in the file are reported next to the buttons. If nothing is selected, all markers are used.

Output

Every run is a step: a folder <id>_<label> inside the workspace, created automatically. The label is the one typed above the form, else the tool name. The step folder contains:

  • reports/: <name>_tables.xlsx, one XLSX file with one tab per table (if XLSX is checked), and/or <name>_tables_tsv/ with one TSV per table (if TSV is checked);
  • data/: the split FCS files, to continue the analysis (see Split FCS mode);
  • split_fcs_report.html: a summary report; console.log, run_parameters.json and session_info.txt: what was run and how.

All tables are 2D. Rows are identified by cluster_no and cluster_name.

  • MFI cluster x marker and IQR cluster x marker: median and interquartile range of the heatmap markers per cluster, all files pooled;
  • Count cluster x file and Freq (%) cluster x file: number of cells per cluster and file, and their percentage among the cells of each file;
  • MFI (cluster x marker) x file: median of the report markers, one row per cluster and marker combination, files as columns (empty when a cluster has no cell in a file).
